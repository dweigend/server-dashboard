# Persönliche Projektpflege

Dieses Repository dokumentiert und entwickelt mein persönliches Dashboard.
Es ist öffentlich einsehbar, aber kein Community-Projekt mit zugesagter
Unterstützung, Roadmap oder Beitragsannahme. Eigener Code und Designmaterial
werden nicht unter einer Open-Source-Lizenz angeboten. Abhängigkeiten behalten
ihre jeweiligen Lizenzen.

Für die eigene Entwicklung: kleine Änderungen, englische Bezeichner und
Commit-Texte, deutsche Oberfläche, zentrale Gestaltung in `src/app.css`.
Vor einem Commit `bun run validate` ausführen. UI- und Vertragsänderungen
zusammen dokumentieren. Feature-Branches verwenden `codex/<topic>`.

Private Daten, Aufnahmen, Originalreferenzen und Zugangsdaten gehören nicht
ins Repository. GitHub-Push und Server-Deployment sind getrennte Schritte.
